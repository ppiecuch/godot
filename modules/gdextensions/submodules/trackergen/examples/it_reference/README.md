# .it reference demos (music data, not engine input)

A small set of Impulse Tracker (`.it`) modules kept as **reference/inspiration**
for authoring trackergen songs. trackergen does **not** import or play `.it`
files — open these in a real tracker (Schism Tracker, OpenMPT) to study how the
pattern + instrument(kit) + order model is used in practice, then hand-author the
equivalent as `TrackerSong` / `TrackerPattern` / `ChordProgression` resources.

## Files

| File | Source folder |
|---|---|
| `necros-tangerine_fascination.it` | favorites |
| `rockthat.it` | miscellaneous |
| `ONIVA.IT` | tracker-music-playlist-from-1999 |
| `Twilight.it` | tracker-music-playlist-from-1999 |

Downloaded from https://github.com/churris-x/trackers (a personal tracker-music
playlist). Verified to carry the `IMPM` (Impulse Tracker) signature.
